Hantofix

Recolte automatique du Millet sur un itineraire de 36 cartes, avec detection par vision artificielle.

Telecharger pour Windows

Windows 10 / 11 (64 bits) - environ 380 Mo - aucune autre installation requise.

Installation

  1. Lance Hantofix-Setup-1.0.0.exe.
  2. Si Windows affiche « Windows a protege votre ordinateur », clique sur Informations complementaires puis Executer quand meme.
  3. Ouvre Hantofix et cree ton compte.
  4. Choisis une offre dans l'application et contacte-nous pour le paiement par virement.
  5. Une fois ta licence activee : Activer cet appareil, puis Calibrer l'OCR (jeu lance), puis Start.
